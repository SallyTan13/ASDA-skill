## Pattern: Visual Evidence Systematic Interpretation

**Description:** Financial visual evidence requires a structured, multi-dimensional quantitative comparison approach that systematically checks deviations against predefined policy thresholds.

**When to Use:** Analyzing financial allocation data, performance reports, or investment portfolios with defined policy bands or target allocations

**Procedure:**
1. Identify all relevant quantitative parameters in the visual evidence (allocation percentages, bands, targets)
2. Create a systematic comparison matrix:
   - Current allocation
   - Target allocation range
   - Deviation from target
   - Magnitude of deviation relative to policy thresholds
3. Apply a strict threshold test:
   - Classify as "needs adjustment" ONLY if deviation exceeds policy-defined limits
   - Avoid over-inclusion by requiring clear, measurable policy violations
4. Prioritize findings based on:
   - Magnitude of deviation
   - Potential portfolio risk impact
   - Proximity to policy boundaries

**Example:**
> **Scenario:** University endowment portfolio review
> **Wrong approach:** Identifying multiple asset classes as needing adjustment without strict policy threshold validation
> **Correct approach:** 
> - Cash: 1% allocation (15% band) = No adjustment needed
> - Private Equity: 21% (20-25% band) = Slight over-allocation, requires adjustment
> - Public Equity: 39% (30-40% band) = Within policy limits, no adjustment needed

The refined pattern addresses the root cause by introducing a more rigorous, systematic approach to interpreting visual financial evidence, preventing over-inclusion and ensuring only meaningful deviations trigger rebalancing recommendations.
## Pattern: Contextual Date and Time Interpretation

**Description:** Financial documents require precise contextual understanding of dates, avoiding naive literal interpretations.

**When to Use:** Analyzing financial documents with multiple date references, Bloomberg terminals, historical records

**Procedure:**
1. Always establish reference timestamp explicitly
   - Identify document creation date
   - Compare all dates relative to this reference point
   - Calculate time differences precisely

2. Develop multi-dimensional date reading:
   - Track maturity dates
   - Understand forward-looking vs historical perspectives
   - Consider time-based financial implications

3. Systematic date verification:
   - Cross-reference multiple date fields
   - Calculate exact time differences
   - Consider financial instrument-specific date conventions

4. Avoid common date misinterpretation traps:
   - Do NOT assume current date is reference point
   - Always explicitly state reference timestamp
   - Calculate time differences mathematically

**Example:**
> **Scenario:** A bond document from 1997 with a 2002 maturity date
> **Wrong approach:** Assuming 2002 date means past maturity
> **Correct approach:** Calculate time from 1997 document, recognize 2002 is a future maturity date

## Pattern: Multi-Dimensional Financial Attribution Analysis

**Description:** Financial performance attribution requires holistic analysis across multiple dimensions, avoiding single-factor interpretations.

**When to Use:** Analyzing performance reports, sector allocation, return decomposition

**Procedure:**
1. Comprehensive dimensional mapping:
   - List ALL dimensions in the attribution table
   - Track contributions across each dimension
   - Understand interaction between dimensions

2. Systematic comparison technique:
   - Compare portfolio vs benchmark values
   - Calculate relative and absolute differences
   - Assess marginal contributions systematically

3. Nuanced contribution analysis:
   - Do NOT focus on single column/factor
   - Understand how factors interact
   - Calculate net and marginal contributions

4. Verification steps:
   - Sum contributions across dimensions
   - Check total performance reconciliation
   - Validate individual factor interpretations

**Example:**
> **Scenario:** A multi-sector investment performance table
> **Wrong approach:** "This sector looks good because it's positive"
> **Correct approach:** Calculate relative sector contributions, assess benchmark-relative performance, understand interaction between allocation and selection effects
